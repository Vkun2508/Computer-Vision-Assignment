# Computer Vision Assignment - Image Enhancement

## Objective

To perform image enhancement techniques using Python and OpenCV.

## Techniques Implemented

- Grayscale image processing
- Gaussian Blur
- Image Sharpening
- Unsharp Masking
- High-Boost Filtering
- Comparison of different High-Boost values
- Dark and Bright Region Separation
- Gamma Correction
- Adaptive Local Enhancement
- Histogram Comparison

## Tools Used

- Python
- Google Colab
- OpenCV
- NumPy
- Matplotlib
